### 4-2. 모집 페이지 카피 (파이 스쿨 톤)

---

#### 히어로

**Layer (가제)**
AI 시대, 디자이너의 눈과 손을 다시 묻는 이미지 프로그램

---

#### 본문

AI가 이미지를 만드는 시대에 디자이너는 무엇을 하는가.

프롬프트 한 줄이면 100장이 쏟아진다.
그러나 그 100장 중 1장을 고르는 것은 여전히 사람의 일이다.

이 프로그램은 도구 사용법을 가르치지 않는다.
**보는 눈을 세우고, 만드는 손을 단련한다.**

---

**6주, 두 개의 막.**

Act 1에서 눈을 세우고 도구를 익힌다.
Act 2에서 만들고 부수고 다시 만든다.

매주 실무에 바로 쓸 수 있는 결과물이 나온다.

---

**파이프라인**

아이디에이션 → 3D 모델링 → 최종 렌더샷.
방향 → 구조 → 표면 → 판단.

이 순서를 지키면 도구가 바뀌어도 프로세스는 남는다.

---

**누구를 위한 프로그램인가**

디자인을 전공했고 실무를 하고 있는 사람.
AI 도구를 써봤지만 "내 의도대로" 나오지 않아 답답했던 사람.
도구 튜토리얼이 아닌, 자신의 판단력 위에 새로운 생산 방식을 얹고 싶은 사람.

### 4-3. SNS 콘텐츠 전략

**Instagram 콘텐츠 유형:**

| 유형 | 예시 | 빈도 |
|------|------|------|
| **프로세스 릴스** | 믹스보드→블렌더→나노바나나 30초 타임랩스 | 주 2회 |
| **Before/After** | 블렌더 밋밋한 렌더 vs 나노바나나 최종샷 | 주 1회 |
| **크리틱 카드** | "이 이미지의 문제점은?" 퀴즈형 | 주 1회 |
| **수강생 결과물** | (2기부터) 실제 수업 결과물 공유 | 수업 후 |

**톤앤매너:**
- 파이 스쿨처럼 선언적이되, 더 짧고 직관적으로
- "쉽다/빠르다" 표현 안 씀
- 결과물 이미지가 말하게 함 — 설명 최소화

## 5. 디자인 가이드

### 5-1. 비주얼 아이덴티티 (가이드라인)

| 요소 | 방향 |
|------|------|
| 톤 | 절제된, 선언적, 깊이 있는 |
| 컬러 | 모노크롬 베이스 + 악센트 1색 (TBD) |
| 타이포 | 산세리프 한글 + 영문. 깔끔한 위계 |
| 이미지 | 프로세스 중심 — "결과물"보다 "만드는 과정"을 보여줌 |
| 레이아웃 | 여백 많이. 텍스트 적게. 이미지가 주인공 |

### 5-2. 피해야 할 것

- 네온/그라디언트 등 "AI 느낌" 비주얼
- 별점/수강평 개수 강조 (첫 기수에는 없으니까)
- "~만에 마스터" 류 약속
- 도구 로고 나열식 레이아웃

## 8. 향후 확장

이 프로그램은 "이미지 생성" 모듈이다.
처음 제안했던 전체 커리큘럼의 1번에 해당한다.

```
★ 1. 이미지 생성 — Layer (현재)
  2. 콘텐츠 생성 — SNS 자동화 (다음)
  3. 웹사이트 관리
  4. PPT / 기획서
  5. 매출/입출고 관리
```

1기가 성공하면:
- **같은 수강생 대상 심화**: 상세페이지 자동화 (Figma + GAS 연동)
- **새 수강생 대상 확장**: 2번 콘텐츠 생성 모듈
- **VOD 전환**: 오프라인 검증 후 온라인 녹화 버전 제작
